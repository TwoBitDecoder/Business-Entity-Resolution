# Roadmap

## Phase 1 — Data understanding
- Dataset audit and integrity checks
- Singleton/match multiplicity analysis
- Missingness and country distributions
- Positive-pair similarity analysis

## Phase 2 — Retrieval baseline
- Character TF-IDF indexes
- Exact/high-confidence rules
- Recall@K and candidate reduction analysis

## Phase 3 — Matcher baseline
- Candidate-derived hard negatives
- Fuzzy, token, numeric and retrieval features
- LightGBM
- Macro F0.5 threshold tuning

## Phase 4 — Advanced experiments
- Multilingual dense retrieval
- Transformer reranking
- Ensembles only if validation justifies complexity

## Phase 5 — Finalization
- Error analysis
- Full-test inference
- Submission validation
- Reproducibility and methodology documentation
